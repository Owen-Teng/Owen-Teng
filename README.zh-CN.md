## 我正在发展的一个判断

**先重构工作，再依据真实运行证据调整岗位、组织与激励。**

组织建设、HR 数字员工和学习产品的实践，让我持续追问：完整结果由谁负责、人的判断应放在哪里，以及下一次工作怎样做得更好。
